# История изменений

## 1.1.0

- Фильтр `MaxBot::setUpdateFilter()` может вернуть `Update` для замены исходного обновления перед обработкой.
  `true` допускает исходное обновление, `Update` заменяет его, `false` отклоняет.
- Поле `user` в `BotAddedToChatUpdate` и `BotRemovedFromChatUpdate` стало необязательным.
  Методы `getUser()` моделей и событий, а также `getUserId()` событий возвращают `null`, если пользователь не передан.
- Уточнено описание `User::getUsername()`: никнейм возвращается только для ботов.
- Версия схемы API обновлена с `0.0.33` до `0.0.34`.
- Добавлен `BaseResponseModel::newFromJson()` для создания моделей ответа из JSON.
- При сериализации PHP модели ответов сохраняют только исходные данные `$data` и восстанавливают их при десериализации.
- Добавлена проверка типов обязательных полей обновления через `Update::validateData()`.
- Методы `MaxBot::validateRequestHeaders()` и `MaxBot::validateRequestBody()` стали публичными
  для самостоятельной проверки Webhook-запросов.
- Добавлены константы `MaxBot` для имён заголовков и ключей `$_SERVER`.
- Исправлено чтение тела Webhook-запроса: строка `"0"` больше не считается пустой.
- Незначительные улучшения валидации и обработки Webhook-запросов.
- Ужесточена проверка версии схемы API, идентификаторов сообщений и токенов видео:
  значения с завершающим переводом строки больше не допускаются.
- `RawModel::offsetSet()` выбрасывает `RequiredArgumentException`, если ключ не указан,
  в том числе при записи через `$model[]`. Уточнены типы ключей доступа к моделям запросов и ответов.
- Расширены модульные тесты моделей и проверок Webhook-запросов.
- Обновлены настройки Psalm и PHP CS Fixer, удалены избыточные PHPDoc-аннотации и подавления ошибок анализа.
- Уточнена документация по обработке обновлений: терминология, проверки Webhook-запросов и описания методов.
  Добавлены примеры сохранения и восстановления обновлений в JSON и формате сериализации PHP.
- Описания консольных утилит собраны в разделе инструментов, примеры запуска адаптированы для установки через Composer.
- Исправлены ссылки на официальную документацию API.

## 1.0.0

Крупное обновление всего пакета: переработаны HTTP-клиенты, контракты, модели и валидация,
добавлены обработчики на основе атрибутов. Расширено покрытие тестами, добавлена CI-проверка.

Для перехода с `0.x` на `1.0` см. [руководство по миграции](docs/MigrationTo1.0.md).
